About CODEMIND

An interactive programming trainer: learn by solving, debugging and proving your skills.

Team

Developer / System Owner: Roniel Nyke Gonzales

Sponsor: Iloilo Tech Company — Iloilo City

Code used to build this system
  • HTML5 — one separate page per section (index, tracks, quiz, badges, certificate, about)
  • CSS3 — style.css: animations, glassmorphism, responsive design, cinematic intro
  • Vanilla JavaScript (ES6+) — one script per page plus shared files
  • Bootstrap 5.3 and Bootstrap Icons — grid, navbar, cards, tables, toasts
  • Canvas API — intro background and certificate image
  • Web Audio API — intro sound (always on)
  • LocalStorage — saving progress in the browser
What you can learn

HTML, CSS, JavaScript, PHP, SQL, React, Python, Java, Flutter, Login System, Rest Api + Database and Scalable Backend These are the topics of the quiz; they were not used to build the system.
